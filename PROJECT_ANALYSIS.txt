│ 8. PricingEngine: يحمّل tiers من Supabase لحساب الأسعار                     │

┌─────────────────────────────────────────────────────────────────────────────┖
│ إضافة منتج للسلة                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. المستخدم يضغط "أضف للسلة" (product-detail.js أو bought-together.js)      │
│ 2. store.js: addToCart(product, quantity, options)                           │
│ 3. يتحقق من تسجيل الدخول (localStorage.isLoggedIn)                          │
│ 4. ينشئ cart item مع: id, name, price, quantity, image, source,             │
│    taager_product_id, country_code, seller_id, etc.                          │
│ 5. يحفظ في localStorage (cart_<email> أو cart)                               │
│ 6. يحدث عداد السلة في الهيدر (updateCartCount)                               │
│ 7. يعرض toast notification (notifyCartAdded)                                 │
│ 8. إذا مزامنة مفعلة: syncCartToSupabase() → table cart_items                 │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ إنشاء طلب (Checkout)                                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. checkout.js: يجمع بيانات الشحن، الدفع، الكوبون                           │
│ 2. ينشئ كائن order: user_name, email, phone, address, total_price, items   │
│ 3. supabase-client.js: createOrder(order, items)                            │
│ 4. يحاول بإدخال مباشر مع columns مكتشفة ديناميكياً                          │
│ 5. إذا فشل: fallback patterns (12 pattern مختلف لأسماء الأعمدة)             │
│ 6. ينشئ order_items مرتبط بالطلب                                           │
│ 7. يحفظ snapshot محلي للطلب (localStorage)                                  │
│ 8. إذا منتجات Taager: يبعث طلب لـ Taager API عبر taager-proxy               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ مزامنة منتجات تاجر (Taager Sync)                                               │
├─────────────────────────────────────────────────────────────────────────────┤

│ 2. يومي: refresh_token_daily.bat (Windows Task Scheduler)                   │

│    - fetchLiveProducts() → Taager API (variants + highlights)               │

│    - persistProducts() → upsert في taager_products table                   │
